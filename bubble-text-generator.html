Outline or filled?

Outlined bubbles (Ⓑⓤⓑⓑⓛⓔ) are light and playful, and they render on almost every device — this set has been in Unicode for decades as part of the Enclosed Alphanumerics block.

Filled bubbles (🅑🅤🅑🅑🅛🅔) are far heavier and read almost like a logo. They are newer additions, so support is slightly narrower, and on some phones they render in colour as emoji-style glyphs rather than matching your text.

Mixed case: the filled set only has one case, so upper and lowercase letters look identical. The outlined set has both — Ⓐ and ⓐ are distinct characters.

Digits and where they come from

Circled digits exist but come from a different part of the block, which is why they sometimes look slightly out of step with the letters. Circled zero (⓪) was added much later than ①–⑨, so a phone number or a year may render unevenly across older devices.

If a string of numbers looks wrong, the safest option is to leave digits plain and bubble only the letters.

Good uses for circled letters

  • Playful usernames — reads as friendly rather than edgy.
  • Step markers — ① ② ③ in a how-to caption, which survives platforms that strip list formatting.
  • Emphasising a single word in an otherwise plain caption.
  • Kids' and craft accounts — the rounded shapes match the subject matter.
  • Poll options — Ⓐ Ⓑ Ⓒ in a plain-text post.

Not ideal for long text: circled letters are wide and heavily spaced, so a full sentence takes up an enormous amount of room.

Things to know before you commit

The trade-offs worth knowing

  • Search engines and site search may not match it. To a computer, 𝓱𝓮𝓵𝓵𝓸 is not the word hello. Keep your searchable text plain.
  • Screen readers handle it badly. Many announce the characters one by one or skip them, so avoid styling text that carries important information.
  • Some fonts lack the glyphs. Where a device has no glyph you get a box (□). Coverage is very good on modern phones and desktops, weaker on older devices and some smart TVs.
  • A few platforms filter it from names. Facebook and some games restrict which characters may appear in a real-name field.

None of that matters for a bio, a caption or a username. All of it matters for body text, headings on your own website, or anything you want found in search.

Frequently asked questions

What is bubble text?

Bubble text replaces each letter with a Unicode character that shows the letter inside a circle. It is a set of real characters, so it copies and pastes anywhere.

Why do filled bubbles look like emoji on my phone?

Some systems render the newer filled characters using the colour emoji font. Use the outlined style for consistent monochrome text.

Are there bubble numbers?

Yes, ⓪①②③ and so on, though they come from a different part of the Unicode block and can look slightly inconsistent on older devices.

Does bubble text work on Instagram?

Yes, in bios, captions and comments.

Why do uppercase and lowercase look the same in filled bubbles?

The filled set has only one case in Unicode. Use the outlined bubbles if you need a visible difference.

Can I use bubble text in a Discord nickname?

Yes. Keep it short, since circled characters are wide and nicknames have a length limit.
