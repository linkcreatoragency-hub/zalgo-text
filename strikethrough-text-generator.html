How the line is drawn

Unlike the fancy-font styles, this effect does not replace your letters. It keeps them exactly as they are and inserts a zero-width combining mark after each one. The mark has no width, so it draws on top of the character that came before it.

That has a useful consequence: the underlying text is unchanged. Search still matches it, screen readers still read the words, and stripping the marks restores the original perfectly — which is exactly what the Zalgo to normal text tool does.

The three styles

  • Strikethrough (s̶t̶r̶i̶k̶e̶) — a horizontal line through the middle. The standard crossed-out look, and the one with the widest font support.
  • Slashed (s̸l̸a̸s̸h̸) — a diagonal stroke. Reads more like cancelled or not allowed than deleted.
  • Wavy (w̴a̴v̴y̴) — a tilde overlay. Softer and more decorative, and it doubles as a light glitch effect.
Gaps between letters: because each mark attaches to one character, the line can look very slightly broken in some fonts rather than perfectly continuous. Monospaced and system fonts render it most cleanly.

Why people use it

  • The joke correction — I̶ ̶h̶a̶t̶e̶ ̶M̶o̶n̶d̶a̶y̶s̶ I love Mondays. Instantly readable as humour.
  • Sale prices — cross out the old price next to the new one in a caption.
  • Done lists — mark finished items in a plain-text note or Trello card.
  • Retractions — show what changed instead of silently editing it.
  • Spoiler-ish redaction — a visual hint that something was removed.

Where markdown exists — Discord's ~~text~~, Slack, Reddit, WhatsApp — use it instead. It is cleaner and more accessible. This tool is for everywhere else.

Things to know before you commit

The trade-offs worth knowing

  • Search engines and site search may not match it. To a computer, 𝓱𝓮𝓵𝓵𝓸 is not the word hello. Keep your searchable text plain.
  • Screen readers handle it badly. Many announce the characters one by one or skip them, so avoid styling text that carries important information.
  • Some fonts lack the glyphs. Where a device has no glyph you get a box (□). Coverage is very good on modern phones and desktops, weaker on older devices and some smart TVs.
  • A few platforms filter it from names. Facebook and some games restrict which characters may appear in a real-name field.

None of that matters for a bio, a caption or a username. All of it matters for body text, headings on your own website, or anything you want found in search.

Frequently asked questions

How do I strike through text on Instagram?

Instagram has no strikethrough option, so type your text above, copy the result and paste it into your caption or bio.

Does strikethrough text still search correctly?

Yes. The underlying letters are unchanged — only invisible marks are added — so search and copy-paste still find the real words.

Why does the line look broken?

Each mark is attached to one character, so some fonts leave hairline gaps between them. It is a rendering detail, not a fault in the text.

Can I remove strikethrough later?

Yes, paste it into the Zalgo to normal text tool to strip the marks and recover the original.

Does it work on Discord?

Yes, though Discord supports ~~double tildes~~ for proper strikethrough, which is the better option there.

Is strikethrough accessible?

More accessible than font-swapping styles, since the letters are unchanged. Screen readers may still announce the marks, so avoid it for critical information.
